# dataset 猫图库评测报告

生成时间：2026-10-28T14:37:00

## 1. 测试设置

本次直接使用 `dataset/metadata.jsonl` 已有的固定标签和划分，没有按识别结果挑图。平台仅支持猫，因此只取 `species=cat`：

| 部分 | 个体/图片数 | 用途 |
| --- | ---: | --- |
| dataset gallery | 80 只猫、230 张原始图片、229 张成功建立向量 | 作为平台中的发现猫线索 |
| positive query | 80 只猫、每只 1 张，共 80 张 | 测试能否找回图库中的同一只猫 |
| unknown query | 20 只猫、每只 1 张，共 20 张 | 测试库外猫是否产生错误候选 |

评测对应当前网页的实际全图库范围：共 152 条活跃发现线索、1757 个向量，其中包含新导入的 80 条 dataset 线索，也包含原有样例和用户线索作为干扰项。查询时不填写地点、时间、毛色等筛选条件。每条发现线索的全部成功索引图片都参与比较，同一条线索取最高余弦相似度。模型为 `pet-recognition-base:8691f5f6d0ce:21045851f390`，候选显示阈值为 `0.45`。

## 2. 实测结果

| 指标 | 结果 |
| --- | ---: |
| Top-1（正确猫排第一，不看阈值） | **70/80 = 87.5%** |
| Top-5（正确猫进入前五，不看阈值） | **75/80 = 93.8%** |

| 正查询检测失败 | 1/80 |

Top-1 的 Wilson 95% 置信区间为 78.5%–93.1%；库外误候选率区间为 38.7%–78.1%。

## 4. 结果解释

Top-1/Top-5 衡量固定测试图片的正确身份排序；Recall 还要求分数超过当前显示阈值。库外误候选率衡量图库中没有同一只猫时，系统是否仍给出候选。余弦相似分不是“同一只猫的概率”，页面结果仍需结合多张照片、地点和时间人工核对。此次没有使用 query 图片训练或调参，但不能据此证明通用预训练过程从未接触相关来源图片。
