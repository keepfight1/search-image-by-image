# 原仓库基线审计

审阅点：`9d2b33b7a2c26dd3f49b01405e5abeaa204defc2`。修改前原后端 8 项测试通过，前端 Vite 构建通过。原实现由 Vue 3、FastAPI、SQLite、PetReID 实验代码组成。

| 发现 | 处理 |
| --- | --- |
| 默认图像特征为 16×16 颜色/亮度轻量向量，不能作为同猫识别 | 正式配置改用检测器 + 个体 ONNX 模型，缺权重时启动报错；轻量模式只留测试 |
| `algorithm/weights/best.pt` 缺失 | 不复用旧报告中的 PetReID 准确率，保留实验代码 |
| 旧搜索只使用首图，按区硬筛且返回联系人 | 新 API 多图检索、按记录聚合，公开结果脱敏；旧接口部署时关闭 |
| 数据集旧脚本有合成城市/时间、PetFinder 档案不能可靠当单猫身份 | 新数据选择 Cat Individual Images 的目录身份；数据不导入真实业务记录 |
| Docker Compose 原本只启动后端、默认轻量特征 | 增前端代理和模型挂载；当前机器未安装 Docker，需在目标环境实测 |

当前 SQLite 表仍与旧库兼容，启动时增加用户、会话、联系请求、状态、向量版本字段。升级前需要备份数据库；正式 PostgreSQL/Alembic 迁移尚未完成。
