# 课堂测试用例包

当前候选阈值为 `0.30`。双击 `打开测试材料.cmd`，会同时打开图形化测试页面和当前 Word 测试报告。

1. `测试用例展示.html`：图形化案例和批量指标。
2. `寻猫平台测试报告_阈值0.30.docx`：当前阈值的简明测试报告。
3. `寻猫平台测试报告.docx`：阈值 `0.45` 的历史报告，供前后对比。
4. `典型案例.json`、`批量测试结果.json` 和 `批量测试明细.csv`：可复核结果。
5. 重新生成：`.\.venv\Scripts\python.exe scripts\prepare_teacher_test_cases.py`。

降低阈值会增加召回，同时也会增加库外猫的误候选；结果仍需结合地点、时间和照片人工确认。
