# 课堂测试用例包

双击 `打开测试材料.cmd`，会同时打开图形化测试页面和 Word 测试报告。

## 三个典型演示

1. **同色猫区分**：查看 `01_same_color_*` 三张图。查询猫与干扰猫均为橘白色，正确个体仍排第 1。
2. **地点排除相似猫**：先用 `02_location_query.jpg` 不带地点查询，再选择“武汉市 / 硚口区”。正确猫从第 2 升到第 1，候选线索从 152 条缩小到 26 条。
3. **时间排除不可能线索**：先用 `03_time_query.jpg` 不带日期查询，再把走失日期设为 `2026-01-01`。2025 年的相似猫会被排除，正确猫从第 2 升到第 1。

## 文件说明

- `测试用例展示.html`：离线图形化展示页面。
- `寻猫平台测试报告.docx`：简明的测试方法、案例、批量指标和结论。
- `典型案例.json`：三个案例的完整排名、分数与筛选条件。
- `批量测试结果.json`：汇总指标。
- `批量测试明细.csv`：100 张查询图的逐条结果。
- `images/`：三个案例使用的 9 张固定图片。

80 只图库猫的地点均衡分布为江岸区 27、江汉区 27、硚口区 26；年份分布为 2025 年 40、2026 年 40。

重新生成测试包：

```powershell
.\.venv\Scripts\python.exe scripts\prepare_teacher_test_cases.py
```

注意：结果表示“候选排序效果”，不是自动确认同一只猫。实际寻猫仍需人工核对照片、地点、时间和联系方式。
