## 实际评测结果

评测器通过原有 D 的 API 上传图库和查询，保留 API 图片 ID 到数据集 ID 的映射，按 `pet_id` 判定正确与否。没有改动排序实现。

**本次模型为原仓库 lightweight 联调模型，不是正式 PetReID。阈值 0.72/0.68 取自接口示例，未经过 B 标定。以下结果只作为流程基线，不宣称达到课设目标。**

| 模式 | 物种 | Top-1 | Top-5 | 负样本错误接受率 |
| --- | --- | ---: | ---: | ---: |
| 同物种图片检索，不按地域缩小图库 | 猫 | 50.00% | 75.00% | 100.00% |
| 同物种图片检索，不按地域缩小图库 | 狗 | 25.00% | 41.67% | 100.00% |
| 模拟地域＋阈值完整流程 | 猫 | 66.67% | 87.50% | 100.00% |
| 模拟地域＋阈值完整流程 | 狗 | 33.33% | 66.67% | 100.00% |

纯图片总体 Top-1 为 37.50%，Top-5 为 58.33%；按正样本查询数加权。地域结果受模拟地点和候选规模影响，不能解释为模型识别能力提升。

错误接受率为 100% 说明当前联调特征与示例阈值无法可靠拒绝陌生宠物，不能用于声称“可靠找回”。已附错误案例和图片，供 A/B 改进、标定后重跑。

## 功能与速度检查

`reports/functional.json`：同区命中、同市扩区、不跨城市、定位为空、反向搜索五项均通过。为控制变量，这些功能用例用同一张真实照片上传两次，单独记录，未混入准确率统计。
